# Preposizioni

A small training tool for learning Italian prepositions (level A2).

You are shown an English phrase such as "You live in the city centre" and type the Italian equivalent — verb, preposition and noun ("vivi in centro"). Wrong answers are marked letter by letter, short usage notes explain why a given preposition is used, and every phrase can be marked as learned or postponed, so you keep practising what you don't know yet. Progress and daily points are saved in the browser.

It is a plain static page (HTML and vanilla JavaScript): no build step, no dependencies, no server.

## Try it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000    # then open http://localhost:8000
```
